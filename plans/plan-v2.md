## 十二、视觉风格

**活泼社交风** - 类似百词斩 / 小红书

- 配色：暖色系为主（珊瑚橙 #FF6B6B / 薰衣草紫 #9B5DE5 / 薄荷绿 #00F5D4）
- 布局：卡片式、圆角、大图预览
- 字体：标题用圆润体，正文用清爽无衬线体
- 图标：线性图标 + 微动效
- 整体氛围：温暖、鼓励、有趣

**目标平台：Web + 移动端同步（响应式）**
- 桌面端：完整画板体验（键盘快捷键、大屏操作）
- 移动端：核心功能完整，画板触控优化

## 十三、页面与交互流程

### 13.1 页面地图

```
首页（发现）
├── 每日推荐（今日一画）
├── 热门课程卡片列表
├── 画友动态流
└── 打卡日历入口

课程详情页
├── 课程介绍（画风/技法大纲/难度）
├── 加入课程按钮
├── 学员作品墙
└── 评分分布

技法单元页（当前周）
├── 进度条（本周第几天）
├── Day1: 理论讲解 + 范画拆解
├── Day2-5: 练习列表（每日一画）
├── Day6: 综合小测
└── Day7: AI评分总结 + 通关判定

画板页（核心页面）
├── 左/上: 工具栏（画笔/橡皮/颜色/图层）
├── 中: 画布区域（全屏沉浸式）
├── 右/下: 参考图面板（范画步骤对照）
├── 底部: 步骤进度条（范画渐进链）
└── 顶部: 提交按钮 / 返回

个人中心
├── 我的作品集（网格/时间线视图）
├── 学习进度（各课程通关情况）
├── 技能雷达图（各维度成长曲线）
├── 打卡记录与连续天数
├── 画友管理
└── 设置

社交页
├── 画友动态（关注的人的画作）
├── 画室列表 / 创建画室
├── 画室展览（本周主题投稿）
└── 排行榜
```

### 13.2 核心用户流程

**流程1: 新用户首次使用**
```
打开首页 → 浏览课程 → 选择"通用基础课"（推荐标签）
→ 加入课程 → 进入第1周技法单元
→ Day1 理论讲解 → "开始练习" → 进入画板
→ 完成第一幅画 → AI评分 → 提示"画得不错！明天继续"
→ 引导开启每日提醒
```

**流程2: 每日练习**
```
收到提醒 / 主动打开 → 首页显示"今日一画"卡片
→ 点击进入技法单元 → 今天是Day3练习
→ "开始画画" → 进入画板（参考图已加载）
→ 跟着范画步骤画 → 每步可提交评分
→ 完成提交 → AI评分反馈 → 打卡成功
→ 可选：分享到动态 / 发给画友
```

**流程3: 通关流程**
```
Day7 → AI综合评分 → 显示各项得分
→ 用户自评："我觉得我掌握了" / "还需要练"
→ 双通过 → 通关动画（撒花+颜料币奖励）
→ 进入下一技法单元
→ 未通过 → 本周重练 / 额外练习推荐
```

### 13.3 导航结构

**底部导航栏（移动端）/ 侧边栏（桌面端）：**

| Tab | 图标 | 功能 |
|-----|------|------|
| 发现 | compass | 首页推荐、热门课程 |
| 学习 | book-open | 当前课程、进度 |
| 画板 | pen-tool | 快速进入画板 |
| 动态 | users | 画友、画室、排行榜 |
| 我的 | user | 个人中心 |

## 十四、开发分期计划

### Phase 0: 技术验证（1周）

- tldraw 画板集成验证
- AI评分方案验证（规则引擎 + 大模型API调用测试）
- Nuxt + tldraw 打通demo
- 响应式布局可行性验证

### Phase 1: MVP 核心画板（3周）

**目标：用户能选课、画画、获得AI评分**

- [ ] 用户注册/登录
- [ ] 2个课程数据（通用基础课 + 素描）
- [ ] 课程列表 + 详情页
- [ ] 技法单元页（简化版，线性展示）
- [ ] 画板核心功能（铅笔/橡皮/颜色/撤销重做）
- [ ] 参考图叠底显示
- [ ] 拍照上传
- [ ] AI评分（Phase 1 规则引擎）
- [ ] 基础个人中心（我的作品）

**MVP 验收标准：** 能走通"选课 → 看范画 → 画画 → AI评分"完整流程

### Phase 2: 学习系统完善（2周）

**目标：完整的学习循环 + 通关体系**

- [ ] 范画渐进链（分步骤跟画）
- [ ] 通关判定系统（AI评分 + 用户自评）
- [ ] 打卡系统（日历视图、连续天数）
- [ ] 颜料币系统
- [ ] 技能雷达图
- [ ] 进阶画板工具（图层、笔刷、填充）
- [ ] 课程数据扩充至5个画风

### Phase 3: 社交功能（2周）

**目标：画友互动，提升留存**

- [ ] 画友系统（添加/互相看作品/评论点赞）
- [ ] 画室功能（创建/加入/每周主题/展览）
- [ ] 动态流（关注的人的画作）
- [ ] 排行榜（周榜/月榜）
- [ ] 作品分享

### Phase 4: 商业化 + 打磨（2周）

**目标：付费转化 + 体验优化**

- [ ] 付费墙（高级课程/高级工具/AI详细评分）
- [ ] AI评分升级（接入大模型，语义级反馈）
- [ ] 高级笔刷包
- [ ] 性能优化（画布加载、图片压缩）
- [ ] 数据统计面板

**总计约 10 周**

## 十五、付费点设计

### 15.1 免费内容

- 通用基础课（完整）
- 素描课（完整）
- 基础画板工具（铅笔/橡皮/颜色/撤销重做）
- AI基础评分（总分 + 简短评语）
- 1个画室
- 每日打卡

### 15.2 付费内容（颜料币 / 订阅）

**按项付费（颜料币）：**
- 高级课程解锁（动漫/水彩/油画等）：每门课 99 颜料币
- AI详细评分（逐维度分析 + 改进建议 + 标注图）：每次 10 颜料币
- 高级笔刷包（水彩质感/油画质感等）：每包 49 颜料币

**订阅制（月度会员）：**
- 29 元/月
- 所有课程无限学
- AI详细评分无限次
- 所有笔刷包
- 画室无数量限制
- 专属会员标识

### 15.3 颜料币获取

- 每日打卡：+5
- 通关一个技法单元：+20
- 完成综合测试：+10
- 邀请画友注册：+30
- 首次分享作品到动态：+15

## 十六、用户注册与数据方案

### 16.1 注册方式

- 手机号 + 验证码（主要方式）
- 微信扫码登录
- 后续可扩展 Apple ID / Google 登录

### 16.2 用户数据模型

```
User
├── id, phone, nickname, avatar
├── created_at, last_login
├── level, coins (颜料币)
├── streak_days (连续打卡天数)
└── settings (偏好设置)

Enrollment (用户-课程关系)
├── user_id, course_id
├── current_unit (当前技法单元)
├── status (进行中/已完成)
└── enrolled_at, completed_at

Practice (练习记录)
├── id, user_id, enrollment_id
├── unit_id, day_index
├── image_url (作品图)
├── ai_score (AI评分JSON)
├── self_passed (用户自评)
├── created_at
└── step_index (范画渐进链第几步)

Checkin (打卡记录)
├── user_id, date
└── practice_id

Friendship (画友关系)
├── user_id, friend_id
└── status (待确认/已绑定)

Studio (画室)
├── id, name, creator_id
├── member_count, max_members
└── weekly_theme

Friend (画室成员)
├── studio_id, user_id
└── joined_at
```

### 16.3 图片存储

- 作品图片：对象存储（S3兼容），按 user_id/yyyymm/ 分类
- 参考图/范画：CDN分发，课程内容预置
- 缩略图：自动生成多尺寸（200x200 / 600x600 / 原图）

## 十七、后端技术选型

### 17.1 技术栈

| 层级 | 选择 | 理由 |
|------|------|------|
| 前端框架 | Nuxt 3 (Vue 3) | SSR/SSG、响应式、生态成熟 |
| 画板引擎 | tldraw | 开源、功能完整、可扩展 |
| UI组件库 | 自建 + Tailwind CSS | 灵活定制活泼风格 |
| 后端框架 | Nuxt Server Routes (h3) | 全栈统一，快速开发 |
| 数据库 | PostgreSQL + Supabase | 免费起步、实时功能、内置Auth |
| 对象存储 | Supabase Storage | 与数据库统一管理 |
| AI评分 | Claude API (多模态) | 图像理解能力强 |
| 部署 | Vercel | Nuxt原生支持、自动CI/CD |
| 缓存 | 无（MVP阶段不需要） | 后期按需加 Redis |

### 17.2 为什么选 Supabase

- 免费额度足够 MVP 验证
- 内置 Auth（手机号/邮箱/OAuth）
- 内置 Storage（图片存储）
- 内置 Realtime（社交功能可复用）
- PostgreSQL 功能完整
- 后期如需自建可迁移

### 17.3 API 设计原则

- RESTful 风格
- JWT 鉴权
- 统一错误格式 `{ code, message, data }`
- 版本化 `/api/v1/...`

## 十八、范画渐进链交互细节

### 18.1 画板内步骤展示

```
┌─────────────────────────────────┐
│  [返回]  排线练习 - 第3步/共6步  [提交] │
├────────┬────────────────────────┤
│ 工具栏  │                        │
│ ──铅笔  │     画  布  区  域       │
│ ──橡皮  │                        │
│ ──颜色  │                        │
│ ──撤销  │                        │
│ ──重做  │                        │
├────────┴────────────────────────┤
│  参考图: [Step3: 铺阴影]  ← ─ → │
│  ┌──────────┐                   │
│  │ 范画第3步  │  透明度: ████░ 80% │
│  └──────────┘                   │
├─────────────────────────────────┤
│  ● ─ ● ─ ◉ ─ ○ ─ ○ ─ ○        │
│  1    2    3    4    5    6      │
│ 线稿 底色 阴影 高光 细节 完成      │
└─────────────────────────────────┘
```

### 18.2 交互流程

**步骤切换：**
1. 用户进入画板 → 默认加载第1步参考图
2. 参考图显示在画布旁（桌面端右侧 / 移动端底部弹出面板）
3. 参考图可调节透明度（0-100%），支持叠底模式
4. 用户完成当前步骤 → 点击底部进度条下一步
5. 画布内容保留，参考图切换到下一步
6. 任何步骤都可以点击"提交评分"获取即时反馈

**评分嵌入点：**
- 每步可单独评分（轻量级：完成度 1-5 分）
- 最终完成时：综合评分（4个维度完整评估）
- 评分结果弹窗：分数 + 简短评语 + "查看详细分析"（付费功能）

**跳步机制：**
- 有基础的用户可以跳到中间步骤
- 跳过的步骤标记为"已跳过"，不影响通关判定
- 通关判定只看最终综合评分

**移动端适配：**
- 参考图默认隐藏，点击按钮弹出半屏面板
- 工具栏收起到左侧抽屉
- 双指缩放/平移画布
- 底部步骤条保留

### 18.3 参考图叠底模式

```
模式1: 侧边对照（默认）
  - 参考图在画布旁边，方便对照

模式2: 半透明叠底
  - 参考图直接覆盖在画布上
  - 用户在参考图下方画
  - 适合纯临摹模式

模式3: 分屏对比
  - 左半屏参考图，右半屏用户画布
  - 移动端可上下分屏
```
