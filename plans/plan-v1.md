# paintCloud 产品计划 v1

> 绘画界的百词斩 - 多画风练习平台
> 创建日期：2026-03-28

---

## 一、产品定位

paintCloud 是一个绘画练习平台，核心模式对标百词斩的"选书-每日学习-斩-打卡"循环，但将场景从背单词替换为绘画技法练习。

**一句话描述：** 选一个画风课程，每周练一个技法，跟着范画一步步画，AI评分反馈，打卡坚持。

---

## 二、核心循环

```
选画风课程 → 每周一技法 → 跟着范画逐步练习 → AI评分+自评 → 通关 → 下一技法
```

| 百词斩 | paintCloud |
|--------|------------|
| 选词书 | 选画风课程 |
| 每天学几个新词 | 每周练一个技法 |
| 看图选义 | 看范画逐步临摹 |
| "斩"掉已掌握的词 | AI评分+用户自评，双通过即通关 |
| 间隔复习 | 间隔重练已学技法 |
| 铜板/打卡 | 颜料币/每日一画打卡 |
| 同桌/小班 | 画友/画室 |

---

## 三、学习节奏

一周 = 一个技法单元：

```
Day 1: 看讲解 + 范画拆解（理论输入）
Day 2-5: 每天围绕该技法画一幅练习
Day 6: 综合小测（用该技法画新主题）
Day 7: AI评分总结 + 决定是否通关
```

---

## 四、通关判定

双重判定机制：AI评分 + 用户自评

**AI评分维度（每项1-5分）：**
- 技法准确度 - 本次练习的特定技法用对了没
- 造型能力 - 形体/比例是否合理
- 光影表现 - 明暗关系是否正确
- 整体完成度 - 画面是否完整

**通关条件：** 技法准确度 >= 4 且 用户自评确认通过

### 5.2 课程结构

- 第1周：线条与排线
- 第2周：几何体光影
- 第3周：静物质感
- 第4周：石膏像
- 第5周：人物肖像
- 第6周：速写

## 六、内容体系

### 6.1 内容生产方式

AI生成 + 人工审核：
1. 定义技法大纲
2. AI生成范画（Stable Diffusion / Midjourney 按风格生成）
3. AI生成步骤分解图（ControlNet/图生图逐步生成）
4. AI生成技法讲解文字（Claude/GPT）
5. 人工审核修改，确保准确性
6. 录入课程系统

### 6.2 单个技法单元内容结构

```
[理论]
├── 技法讲解图文
└── 要点清单（3-5个核心要点）

[范画渐进链]（核心特色）
├── 一张成品画拆成 4-6 步
│   例：线稿 → 铺底色 → 阴影 → 高光 → 细节 → 完成
├── 用户跟着每一步画，逐步提交AI评分
├── 多张范画（不同难度/主题）
└── 常见错误对照（正确 vs 错误示例）

[练习]
├── 基础练习 x2（跟着步骤画）
├── 自由练习 x2（给定主题自由发挥）
└── 综合测试 x1（新主题，检验掌握度）

[评分]
├── 该技法专项评分维度
└── 达标分数线
```

### 6.3 范画渐进链详细说明

用户跟着步骤画，每步提交评分：
- Step 1: 用户跟着画 → 提交 → AI评分 → 进入下一步
- Step 2: 继续 → 提交 → 评分 → 下一步
- ...
- 最后一步完成 → 得到完整作品 + 综合评分

不同水平用户可以：
- 新手从 Step 1 开始
- 有基础的人跳到中间步骤

## 七、社交功能

### 7.1 画友（1对1）

- 互相看到对方的每日一画
- 互相点赞/评论
- 互相督促打卡（类似百词斩同桌）

### 7.2 画室（小班）

- 5-20人绘画小组
- 每周同一主题各自创作
- 周末"画室展览"，互相投票
- 画室排行榜/活跃度

---

## 八、画板功能设计

### 8.1 技术选型

- 前端框架：Vue + Nuxt
- 画板引擎：tldraw（开源白板，自带画笔/形状/撤销/缩放，可二次开发）
- 画布尺寸：按课程自定义（课程创建时设定）

### 8.2 MVP功能清单

**基础工具：**
- 铅笔/画笔（可调粗细、透明度）
- 橡皮擦
- 颜色选择器
- 撤销/重做

**进阶工具：**
- 图层管理
- 不同笔刷类型（水彩/油画/铅笔质感）
- 填充/油漆桶
- 选区/移动
- 缩放/平移画布

**辅助功能：**
- 参考图半透明叠底（临摹用）
- 网格/透视辅助线
- 分步引导线（显示"先画这里"）

**拍照上传：**
- 拍照上传线下作品
- 裁剪校正后参与AI评分

---

## 九、AI评分方案

**分两阶段：**

**Phase 1 - 规则引擎：**
- 笔触数量/覆盖面积分析
- 颜色使用分析
- 与范画的结构对比（简化版）
- 完成度判定

**Phase 2 - AI模型接入：**
- 接入多模态大模型API（Claude/GPT-4o）
- 语义级评分（"这个眼睛的比例偏大了"）
- 具体改进建议
