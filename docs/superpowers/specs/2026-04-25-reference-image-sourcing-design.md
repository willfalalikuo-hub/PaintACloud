# Reference Image Sourcing Design

## Background

paintCloud is a painting education platform with 42 reference images across 6 basic units and 2 sketch units. All current images are SVG placeholders generated by `scripts/generate-placeholders.js`. This spec defines how to replace them with real images.

## Image Types and Sources

| Type | Directory | Source | Rationale |
|------|-----------|--------|-----------|
| demo (teaching diagrams) | `public/images/references/{unitId}/demo/` | AI generation (Midjourney/DALL-E/SD) | Requires precise teaching annotations (perspective lines, shading zones, proportion grids) unavailable in stock libraries |
| reference (artwork photos) | `public/images/references/{unitId}/reference/` | Free stock libraries (Pixabay/Unsplash/Pexels) first, AI generation as fallback | Real artwork photos are available in stock libraries with clear commercial licenses |

## Sourcing Process

### Phase 1: Build Requirements Spreadsheet

Create a tracking list for all 42 images:

```
unitId / type / filename / Chinese title / description / source strategy (stock/AI) / status
```

### Phase 2: Stock Library Search (reference images)

For each reference image, search Pixabay/Unsplash/Pexels:
- Use bilingual keywords (e.g., "pencil shading sphere" / "铅笔画球体明暗")
- Filter: free commercial use + high resolution
- Download matching images; mark unmatched as "needs AI generation"

### Phase 3: AI Generation (demo images + stock fallbacks)

For demo images and reference images not found in stock libraries:
- Write precise prompts (technique, composition, style requirements)
- Generate using Midjourney/DALL-E/SD
- Select best output, post-process if needed

### Phase 4: Processing and Integration

- Unify dimensions and format: WebP preferred, PNG fallback
- Place files at `public/images/references/{unitId}/{type}/{name}.webp`
- Update `img()` helper in `courses.ts` to preserve original extension (remove `.svg` forced conversion)
- Remove SVG placeholders
- Verify display on canvas.vue and unit/[id].vue

## Technical Changes

1. **Modify `img()` function** in `app/data/courses.ts` (lines 3-4): stop forcing `.svg` extension, preserve original extension from the filename parameter.
2. **Remove placeholder SVGs** in `public/images/references/` after real images are in place.
3. **Path structure unchanged**: `public/images/references/{unitId}/demo/` and `public/images/references/{unitId}/reference/` remain the same.

## License Compliance

- Pixabay/Unsplash/Pexels: free commercial use, no attribution required
- AI-generated images: verify each tool's commercial license terms (varies by platform)
- Maintain a `SOURCES.md` file documenting each image's source and license type

## Scope

This spec covers sourcing and replacing the 42 placeholder images only. It does not cover:
- Overlay/transparency features on the canvas (unimplemented, separate spec)
- Step-based image filtering in the reference panel
- Dynamic image management or admin tooling
