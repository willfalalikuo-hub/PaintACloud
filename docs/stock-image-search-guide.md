## Tips

1. **Keywords to try if results are sparse:**
   - Chinese: 铅笔素描, 排线, 光影, 透视, 头像, 速写
   - Broader English: pencil sketch, graphite drawing, shading exercise, drawing tutorial

2. **Download settings:**
   - Choose the largest available resolution
   - Prefer images with white/light backgrounds
   - Look for clear, educational-style compositions

3. **Post-processing:**
   - Resize to ~800px longest side
   - Save as .jpg (quality 85-90)
   - Ensure file matches the filename in courses.ts exactly

4. **If no suitable result on stock libraries:**
   - Mark the image as "needs AI generation" in SOURCES.md
   - Use the AI prompts in `docs/ai-demo-prompts.md` as templates, adjusting for the specific reference type
